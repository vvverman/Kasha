## Границы готовности

Это тестовые сборки, не подписанные релизы магазинов. Android APK имеет отладочную подпись; iOS IPA требует подписи владельца через SideStore. macOS ещё без Developer ID и нотариализации Apple. Проверка реального микрофона, фоновых прерываний и производительности на конкретных устройствах остаётся ручной.

Автоматические модельные сценарии используют синтезированную речь и ограниченный набор текстов. Они подтверждают запуск новых моделей, обработку данных и исправление наблюдавшихся регрессий, но не безошибочность любой транскрибации или неизменность смысла любого текста. Нормализация — один пользовательский этап с последовательными вызовами Cleanup по фрагментам, а не обещание одного процесса ОС.

Актуальные статусы, точные ревизии и результаты: [проверка AI pipeline в репозитории](https://github.com/vvverman/Kasha/blob/main/docs/verification/AI_PIPELINE_2026_09_22.md).
