## Последнее исправление: реальные часы iOS-теста

На `0d8dca2` iOS run `35757676478` завершился с одной ошибкой среди 404 тестов. XML `IosLocalModelsExecutionTest` прямо сообщает `Timed out after 15m of _virtual_ (kotlinx.coroutines.test) time`: `LocalTextRoles.withTimeout` работал на виртуальных часах `runTest`, тогда как нативная модель исполнялась на `Dispatchers.Default`.

В `99226cc` весь сценарий настоящих моделей исполняется через `withContext(Dispatchers.Default)` внутри прежнего `runTest(timeout = 20.minutes)`. Сохранены внешний лимит 20 минут, внутренний таймаут нормализации 900 секунд, проверки трёх ролей, PCM/AAC, имён/чисел/отрицания и неизменности аудио. Production-код и веса не менялись, проверки не удалялись. Поведение виртуального и настоящего времени соответствует [документации kotlinx.coroutines.test](https://kotlinlang.org/api/kotlinx.coroutines/kotlinx-coroutines-test/).

Новый run **`35761280789`** завершился **success**. Проверен artifact **`10711146940`**, SHA-256 ZIP **`8b949e7f5ddc0ace03707692f105f3f2175ebeca900de1ded7a41aaadd06f71f`**. ## Поставляемое поведение

Выбор моделей един: Whisper Large-v3 Turbo Q5, Cleanup 0.6B, F2LLM-v2 80M. После STT не запускаются обязательные Cleanup и routing. Транскрибация и нормализация хранятся раздельно; первая активация нормализации запускает TEXT, последующее переключение использует сохранённый результат. Контекстный повтор перезапускает только активный этап; новая транскрибация сбрасывает устаревшие результаты.

Нормализация использует общий код подготовки явных поправок и проверки каждого фрагмента. Это один пользовательский TEXT-этап с последовательными вызовами модели, а не один процесс ОС. Получение частичного ответа или защитный отказ не выдаются за успешную нормализацию. Прежнее содержимое заметки при append не переписывается.

Вес Cleanup не заменялся: 396 704 416 байт, SHA-256 `8c405ca3d29af67b21d2147e195b62ea63c84b84be1794b8aa453f31115b4f69`. Состав и контрольные суммы всех трёх моделей остаются в общем `ModelArtifacts.kt`; Core не содержит URL весов или платформенных движков.
