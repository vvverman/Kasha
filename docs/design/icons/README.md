# Kasha Icons: геометрия и движение

Это следующая редакция **существующего Kasha Icons** для передачи в разработку: 42 собственных glyphs, 44 SVG с учётом двух дополнительных состояний completion, все 22 прежних `Glyph` сохранены в карте соответствий. Production-код не изменён. Каталог не подключает второй набор иконок в приложение.

Откройте [atlas.html](./atlas.html) обычным браузером. Сервер и сеть не нужны: геометрия SVG и снимок реестра встроены в HTML, JavaScript работает непосредственно через `file://`. Шрифт Geologica загружается из соседнего каталога `../assets/fonts/`; если перенести один HTML без шрифта, останется системный sans-serif. Геометрия и интерактивность сохранятся.

В каталоге доступны:

- поиск по русскому действию, ID и старому имени `Glyph`;
- восемь смысловых категорий;
- выбор иконки, её назначение, текущие aliases, SVG для скачивания;
- просмотр выбранной геометрии в размерах 20 / 24 / 32;
- однократное движение при наведении, фокусе и активации;
- ручной режим «Уменьшить движение», который также всегда уважает системный `prefers-reduced-motion`;
- светлая и тёмная темы;
- Enter/пробел для активации обычных HTML-кнопок, Tab для обхода, видимый focus;
- варианты «не выполнено» и «выполнено» у completion control.

В заголовке показан настоящий [kasha_logo.svg](../../../composeApp/src/commonMain/composeResources/drawable/kasha_logo.svg). Экспортёр сохраняет все значения `path d` побайтно; меняет только цвет заливки на `currentColor` и размер в контейнере. Знак не превращён в букву K или одну из служебных иконок.

| [manifest.json](./manifest.json) | Контрольная сумма источника, список экспортов и карта aliases | Нет; генерируется |
| [contact-dark.svg](./contact-dark.svg), [contact-light.svg](./contact-light.svg) | Векторные контактные листы всех 42 иконок в 20/24/32 | Нет; генерируются |
| [qa.mjs](./qa.mjs) | Статическая/растровая проверка; browser QA при наличии Playwright/Chromium | При изменении проверки |

JSON содержит `grid=24`, `strokeWidth=1.8`, round cap/join, `geometry` из path/line/circle/rect, именованные части `part`, массив aliases и motion каждой части. `variants` у `complete` задаёт те же контуры для пустого и заполненного состояний. Повторные alias не создают дубли SVG.

Декларативный реестр — мастер геометрии. Он не загружается в production при открытии приложения. При переносе нужно генерировать или механически переводить эти команды в существующий Canvas-слой `KashaIcons.kt`, сохраняя этот же реестр как проверяемый источник следующей редакции.

## Сборка и проверка

Из корня репозитория:

```bash
python3 docs/design/icons/export.py
python3 docs/design/icons/export.py --check
```

Первый вызов обновляет SVG, manifest, контактные листы и HTML. Второй проверяет, что экспорт не устарел, ничего не записывая. Сеть и дополнительные Python-пакеты не требуются. Порядок и содержимое детерминированы; временные метки в экспорт не добавляются.

Для растровой проверки нужен Node.js с `sharp`. Для браузерного сценария дополнительно нужны `playwright` и установленный Chromium. В среде подготовки документации зависимости разрешаются через `CODEX_PRIMARY_RUNTIME_NODE_MODULES`; в обычном проекте скрипт сначала ищет стандартные Node-зависимости.

```bash
node docs/design/icons/qa.mjs --static
node docs/design/icons/qa.mjs
```

Статический режим проверяет синтаксис JavaScript, встроенный реестр, aliases, уникальность ID, отсутствие CDN и создаёт контактные листы. Также он растрирует каждый базовый glyph в 20/24/32 и проверяет, что рисунок виден и не касается краёв viewport: 126 проверок.

Обычный режим после этой проверки открывает локальный HTML через Playwright с отключённой сетью, проверяет поиск, категории, Enter/пробел, темы, Reduce Motion, размеры и переполнение на мобильной ширине. Если браузер не установлен, выход `2` означает **browser QA заблокирован**, а не успешную проверку браузера; причина записывается в отчёте.

Фактическая проверка при подготовке: JSON/XML и воспроизводимость экспорта подтверждены; синтаксис JS подтверждён; 126 растров не обрезаны; тёмный и светлый контактные листы проверены визуально. Браузерный запуск в среде подготовки был заблокирован отсутствием Chromium. Попытка штатного скачивания браузера завершилась тайм-аутом сети. PNG в `qa/` — статические рендеры SVG, **не снимки браузера**. Анимации, клавиатурные сценарии и layout HTML требуют запуска `qa.mjs` в среде с браузером; их реализация присутствует, успешное выполнение здесь не заявляется.

## Покрытие канонического набора

| Роль из ТЗ | Геометрия / alias | Правило |
|---|---|---|
| Home / Projects / Tasks / Settings | `home` / `projects` / `tasks` / `settings` | Четыре вкладки |
| Mic / Pause / Resume / Stop / Cancel | `mic` / `pause` / `play` / `stop` / `close` | `RESUME → PLAY`, `CANCEL → CLOSE`; доступное имя зависит от операции |
| Playback Play / Pause / Stop | `play` / `pause` / `stop` | Та же геометрия транспортных действий |
| Seek | Интерактивная временная шкала, роль Adjustable | Отдельный декоративный SVG не нужен; прыжки по времени не добавляются без соответствующих команд |
| Note / Task / Project | `note` / `tasks` / `projects` | `TASK → TASKS`, `PROJECT → FOLDER`; aliases не размножают сущности |
| Edit / Delete / Archive | `edit` / `delete` / `archive` | Delete и Cancel имеют разные последствия |
| Pin / Unpin / Sort / Drag / Search | `pin` / `unpin` / `sort` / `drag` / `search` | SEARCH — готовая геометрия; не основание придумывать поисковый сценарий |
| Calendar / Reminder / Repeat / Complete | `calendar` / `reminder` / `repeat` / `complete` | Повторяется уведомление той же задачи; COMPLETE — контур/галочка, состояние хранит контрол |
| Add / Close / Chevron / More | `add` / `close` / `next` / `more` | `ADD → PLUS`, `CHEVRON → NEXT`; вертикальные направления используют UP/DOWN |
| Language / Theme / Local / Cloud / Privacy | `language` / `theme` / `local` / `external` / `privacy` | `CLOUD → EXTERNAL`; внешняя передача объясняется текстом |
| Speech / Text processing / Routing | `speech` / `text-processing` / `routing` | `SPEECH_TO_TEXT → SPEECH`; TEXT_PROCESSING заменяет визуальный MAGIC |
| Показать / скрыть API-ключ | `visibility` / `visibility-off` | `SHOW/EYE → VISIBILITY`, `HIDE/EYE_OFF → VISIBILITY_OFF`; собственный глаз для уже заданного поля провайдера |

## Геометрия, анимация и доступность

Сетка 24 × 24; основной stroke 1.8 логических единицы. Линия масштабируется вместе с SVG. `vector-effect="non-scaling-stroke"` не применяется. Окончания и соединения округлённые; геометрия держится внутри viewport с запасом. Оптический вес проверяется в нескольких размерах, а не только на увеличении 4×.

Transport glyphs RECORD/PLAY/PAUSE/STOP имеют заливку. Остальные базовые glyphs используют контур; заполненный COMPLETE — отдельный экспорт того же состояния. Функциональные маленькие иконки не получают glow, grain, фотографии и многослойный blur.

Motion — однократные 220–300 мс по вводу. Части могут сдвигаться не более чем на 1 логическую единицу; scale 0.96–1.04. Обычный поворот не превышает 6°, для settings используется короткий поворот 8°. PLUS не вращается в крест, STOP не крутится, SPEECH не выдаёт фиктивную waveform. У текстовой обработки строки аккуратно смещаются и появляется корректирующая галочка. Вечные hover-loop и автономное случайное движение отсутствуют.

У visibility/visibility-off отдельная функциональная анимация века: `scaleY` контура кратко меняется 1 → 0.15 → 1 за 260 мс; диагональ скрытого состояния сохраняется. Это исключение для имитации закрытия века, не уменьшение всего target. Reduce Motion оставляет обычный статичный глаз.

`motion.frames` задаёт offset, translate, rotation, scale и opacity. `origin=[12,12]`; SVG player использует центр viewBox. `draw=true` включает короткое проявление соответствующих штрихов. При Reduce Motion и transform, и draw выключаются. В production `animated` должен следовать реальному событию/состоянию, а не постоянному нахождению указателя над элементом.

Статический SVG имеет `role="img"` и `<title>` для автономного просмотра. Внутри кнопки glyph должен быть декоративным (`aria-hidden` / отсутствие отдельного semantics node), а доступное имя задаётся самой кнопкой: «Начать запись», «Приостановить воспроизведение», «Открепить проект». Нельзя озвучивать пользователю `NEXT`, `MAGIC` или «иконка микрофона» вместо действия.

Target контрола остаётся минимум 44 × 44, предпочтительно 48 × 48; размер рисунка 20–24 не уменьшает target. Изменение checked/selected не определяется только цветом. `COMPLETE` не становится завершённой задачей от факта проигрывания анимации: подтверждённое состояние приходит из Core/repository.

## Перенос в существующий KashaIcons.kt

1. Прочитать [03-components.md](../03-components.md) и [08-graphics-motion.md](../08-graphics-motion.md), затем сверить актуальный enum и call sites в [KashaIcons.kt](../../../composeApp/src/commonMain/kotlin/brain/studio/ui/KashaIcons.kt).
2. Сохранить `KashaIcon` и старые enum-значения на время миграции; использовать `manifest.aliases` как точную карту. Новые роли добавлять туда же.
3. Перевести declarative geometry в общие Canvas path/line/circle/roundRect. Сравнить результат с экспортом в 20/24/32; SVG не становится второй независимой вручную правимой геометрией.
4. Вызовы `MAGIC` перевести на `TEXT_PROCESSING`. Compatibility alias может существовать технически, но пользователь видит только новую семантику и графику.
5. Подключить motion частей к общему motion-профилю и системному Reduce Motion. Не копировать HTML-анимационный runtime в приложение.
6. Обновить ссылки на glyphs в нужных экранах и доступные имена команд. Настоящий логотип остаётся в `KashaBrandSlot`.
7. Проверить существующий `check-ui-boundary.py`, отсутствие второго icon pack, visual comparison и системную доступность на поставляемых платформах.

Этот комплект делает графику и движение конкретными и воспроизводимыми для разработки. Он не меняет состояние задач, аудиоконтракты, AI-провайдеры и правила Core.
