# Фирменная графика

## Официальный знак

Ссылка на [основной](../../../composeApp/src/commonMain/composeResources/drawable/kasha_logo.svg) и [solid](../../../composeApp/src/commonMain/composeResources/drawable/kasha_logo_solid.svg) SVG. Исходные файлы проекта сохраняются побайтно; копии альтернативной геометрии здесь не создаются.

Номинальный `viewBox` основного знака — `0 0 604 739`. При любом размере сохранять исходную пропорцию. Форма знака не становится буквой K, микрофоном или частью checkbox. Монохромное тонирование выполняется в компоненте по семантическому цвету без правки контуров.

## Тёмная макросъёмка гречки

[buckwheat-dark-macro.png](buckwheat-dark-macro.png) — сгенерированный исходник фоновой фотографии, созданный 13.09.2026 встроенной генерацией изображений по прямому пожеланию пользователя. Это изображение гречки, а не настоящий снимок продукта и не готовый UI.

Назначение: только сплеш-экран. Последнее прямое указание пользователя исключает фотографию на idle Home, онбординге и всех рабочих экранах. Применение не является обязательным условием запуска. При отсутствии изображения всегда используется полноценный процедурный фон.

### Размещение

1. `contentScale = Crop` с выравниванием по нижнему правому краю; сохранять форму зёрен, не растягивать изображение по осям.
2. Верхние 55% и центральная область остаются спокойными. Знак находится над изображением отдельным настоящим SVG.
3. Над картинкой располагается слой Canvas `#191715` с начальным alpha `0.30`; в области любого текста накрытие усиливается до необходимого контраста. Значение подбирается по итоговой композиции, а не по самой картинке в просмотрщике.
4. На idle Home фотография отсутствует. Там используются только процедурный Canvas, illumination и при необходимости слабый декоративный знак.
5. При завершении сплеша изображение исчезает вместе с заставкой через opacity за 180–220 мс. При Reduce Motion переход мгновенный или короткий по правилам доступности. Фотография не переносится в состояние записи даже на один промежуточный экран.
6. В светлой теме фотография не инвертируется и не используется. Работает бумажный процедурный фон.
7. На широком сплеш-экране фон не тайлится. Изображение ограничивается центральной композиционной зоной, боковые поля продолжаются Canvas.
8. Нет parallax за курсором, анимации камеры, масштабирования текстуры и пульсирующего зерна.

### Перед подключением в приложение

Исходник здесь предназначен для передачи дизайна. Runtime-версия экспортируется в подходящем сжатом формате с визуальной проверкой banding, профилем sRGB и ограничением размера под фактический экран. Она загружается асинхронно и не задерживает разрешение микрофона или старт записи. Не растягивать огромный PNG в памяти ради едва заметного фона. Параметры и бюджет приведены в [графике и motion](../08-graphics-motion.md).

### Смысл использованного промпта

Фотореалистичная экстремальная макросъёмка жареной гречки в почти полностью тёмном помещении; характерные трёхгранные зёрна похожи на спокойный минеральный ландшафт. Несколько зёрен внизу справа освещены слабым тёплым боковым светом. Малая глубина резкости, коричнево-графитовый фон около `#191715`, верхняя и центральная часть свободны для настоящего логотипа. Без посуды, ложек, дыма, лучей, надписей, логотипов, UI и нарисованного орба.
