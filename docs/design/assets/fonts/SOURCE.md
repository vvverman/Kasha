# Geologica: источник шрифта для передачи дизайна

В этом каталоге находится проверенный исходный variable-шрифт Geologica для просмотра документации и последующего внедрения в Kasha. Размещение здесь не переключает шрифт production-приложения. Порядок внедрения в `prepare-fonts.py` и `Design.kt` описан в [визуальной основе](../../02-foundations.md).

Локально изменено только имя файла для удобного подключения. Таблицы, контуры, имена внутри шрифта и лицензия не редактировались. Историческое имя `Geologisk` в copyright notice не является опечаткой документации и сохраняется как в оригинале.

Проверка бинаря через `fontTools.ttLib.TTFont` дала следующие оси:

| Ось | Минимум | Default в бинаре | Максимум |
|---|---:|---:|---:|
| `wght` | 100 | 100 | 900 |
| `CRSV` | 0 | 0 | 1 |
| `SHRP` | 0 | 0 | 100 |
| `slnt` | −12 | 0 | 0 |

Оси `wdth` и `opsz` отсутствуют. В GSUB/GPOS присутствует feature `tnum`, используемый для таймера. В таблице `cmap` найдены все символы текущего набора `required` из `scripts/prepare-fonts.py` Kasha: отсутствующих символов — 0. Этот набор покрывает используемые приложением русский, английский, испанский, французский, немецкий, украинский, белорусский и казахский алфавиты. Визуальная проверка шейпинга и метрик на устройствах проводится при внедрении отдельно.

Канонические настройки Kasha:

- UI: `CRSV = 0`, `SHRP = 0`, `slnt = 0`, `wght` по роли текста.
- Hero/Display: `CRSV = 1`, `SHRP = 0`, `slnt = 0`, `wght` по роли текста.
- Основной текст: 16/23 sp, вес 400. Таймер: 46/52 sp, вес 560, `tnum`.

Для HTML-атласа шрифт подключается локальным относительным URL. Сетевой запрос к Google Fonts/CDN не нужен. `font-weight` объявляется диапазоном `100 900`, синтетические начертания отключаются, font family не получает резервного брендового serif. Для производственного интерфейса источником настроек остаётся [design-tokens.json](../../tokens/design-tokens.json).
