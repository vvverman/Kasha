# 09. Тексты интерфейса и локализация

## 1. Голос Kasha

Тон спокойный, конкретный, уважительный. Приложение помогает записывать и сохранять мысли, не играет роль собеседника. Нейтральные короткие глаголы предпочтительнее рекламы и объяснения внутреннего устройства.

Кнопка называет действие: «Начать запись», «Продолжить», «Завершить», «В заметки», «В задачи». Статус сообщает происходящее: «Идёт запись», «Расшифровываем». Ошибка называет проблему и доступный следующий шаг. Сообщение об успехе сообщает сохранённый объект и место назначения.

Не использовать эмоциональные восклицания, emoji, «волшебство», «магия ИИ», «нейронка думает», «упс», «что-то пошло не так», «супер», «успешно успешно». Не называть данные «контентом», пользователя — «юзером», проект — «воркспейсом». Не подменять конкретный этап общим «Kasha обрабатывает».

## 2. Продуктовый словарь

| Смысл | Термин в интерфейсе | Ограничение |
|---|---|---|
| Текущий звук с микрофона | Запись | Не «голосовое сообщение»: отправки собеседнику нет |
| Распознанный текст до распределения | Текст записи | Не «черновик» как раздел продукта |
| Постоянный документ в проекте | Заметка | Имя берётся из первой непустой строки |
| Контейнер заметок с контекстом | Проект | Не папка/категория в соседних экранах |
| Подсказка для маршрутизации | Инструкция проекта | Не обещает отдельную LLM-персону |
| Отдельное действие с расписанием | Задача | Одна задача, даже если текст содержит несколько предложений |
| Выполненные задачи | Архив | Не корзина: выполнение не удаляет данные |
| Обработка слов и абзацев | Привести в порядок | Не «улучшить смысл» или «переписать за меня» |
| Speech-to-Text | Распознавание речи | Техническое название роли допустимо в пояснении настроек |
| Routing | Подбор проекта | Пользователь сохраняет окончательный выбор |
| External AI | Внешний сервис | Имя выбранного провайдера показывается рядом |
| Local AI | На устройстве | Только когда исполняемый адаптер подтверждает локальный режим |
| Повтор | Повтор напоминания | Не создание следующей задачи |

Слова «Запись», «Заметка» и «Задача» не взаимозаменяемы в предупреждениях об удалении. Деструктивное сообщение точно указывает, какое содержимое будет потеряно.

## 4. Ошибки и восстановление

Каждое сообщение связывается с типизированной причиной либо достоверно известным фактом адаптера. Нельзя заменять все отказы микрофона, недоступную модель и нехватку места одной строкой `audioFailed`. Не показывать «данные сохранены», если хранилище не подтвердило сохранение.

| Состояние | Основной текст | Действие | Когда допустимо |
|---|---|---|---|
| Нет разрешения микрофона | Нужен доступ к микрофону | Разрешить / Открыть настройки | Действие соответствует текущему статусу permission; повторно запрещённое окно не вызывается |
| Микрофон занят/не найден | Не удалось начать запись. Проверьте микрофон. | Повторить | Нет созданной активной сессии |
| Запись прервана ОС | Запись прервана | Восстановить запись | Есть recoverable файл/журнал; дополнительная строка указывает фактическое сохранённое время |
| Остался pending | Есть незавершённая запись | Восстановить запись | Не выполнять авто-record поверх pending |
| Файл повреждён | Не удалось восстановить аудио | Повторить / Закрыть | Не предлагать восстановленный текст, если его нет |
| Нет модели | Для распознавания нужна модель | Выбрать модель | Отказ действительно связан с моделью; не использовать для запрета Speech permission |
| Запрет Speech на iOS | Разрешите распознавание речи в настройках системы | Открыть настройки | Реальная причина из адаптера |
| Язык недоступен локально | Распознавание этого языка недоступно на устройстве | Настройки распознавания | Не включать внешний сервис автоматически; текущий общий выбор языка интерфейса не менять молча |
| STT не завершён | Не удалось расшифровать запись | Повторить | Источник остаётся доступен; отдельная строка сообщает его фактическую сохранность |
| Речь не найдена | Не удалось распознать речь | Прослушать / Повторить | Пустой результат не выдаётся за успешную заметку |
| Ошибка tidy | Не удалось привести текст в порядок. Исходный текст сохранён. | Повторить | Исходный текст действительно удержан |
| Проверка tidy отклонила ответ | Обработка изменила важные детали. Оставили исходный текст. | Закрыть | Core отклонил числа/имена/отрицания или другие инварианты |
| Ошибка routing | Не удалось подобрать проект. Выберите его сами. | Выбрать проект | Ручное назначение доступно без AI |
| Ошибка локального сохранения | Не удалось сохранить изменения | Повторить сохранение | Текст остаётся в редактируемом состоянии; не скрывать его modal-error экраном |
| Внешний сервис недоступен | Сервис {provider} не ответил | Повторить / Выбрать обработку на устройстве | Локальная альтернатива показывается только если исполнима |
| Согласие отозвано | Передача данных отключена | Открыть настройки | Нет автоматической отправки и смены провайдера |
| Нехватка места | Недостаточно места для записи | Повторить | Нет ложного обещания продолжения записи |
| Уведомления запрещены | Уведомления отключены в настройках системы | Открыть настройки | Задача сохранена; нельзя писать «Напоминание установлено» |
| Устройство не поддерживает возможность | Недоступно на этом устройстве | Пояснение рядом | Причина связана с capability, а не с выбранной эстетикой |

Технические exception, пути файлов, токены, исходные запросы провайдеру и полный ответ API в UI не выводятся. Диагностический идентификатор допустим в раскрываемой служебной детали без пользовательского текста и секретов.

## 5. Подтверждения

| Ситуация | Заголовок | Тело | Кнопки |
|---|---|---|---|
| Отмена активной записи | Удалить эту запись? | Аудио этой записи будет удалено. Восстановить его после удаления не получится. | Продолжить запись / Удалить запись |
| Удаление результата до распределения | Отменить заметку? | Текст этой записи и связанное с ней аудио будут удалены. | Оставить / Отменить заметку |
| Воспроизведение при активной записи | Завершить запись и начать прослушивание? | Текущая запись останется на Главной. | Отмена / Завершить и слушать |
| Удаление задачи | Удалить задачу? | Задача и её напоминания будут удалены. | Оставить / Удалить задачу |
| Удаление используемой модели | Эта модель используется | Сначала выберите другой доступный способ обработки для использующих её функций. | Оставить / Выбрать замену |

Перед подтверждением удаления активную запись ставят на паузу. «Продолжить запись» явно возобновляет ранее активную сессию; если она уже была на паузе, вместо этой подписи используется «Оставить запись». Закрытие удаления через системный Back/свайп сохраняет паузу. В подтверждении переключения на playback «Отмена» сохраняет исходное состояние сессии и не возобновляет ранее приостановленную запись.

Тела деструктивных сообщений должны совпадать с реализованной транзакцией. Если источник разделён с другой сущностью или ещё используется, нельзя обещать/выполнять его безусловное удаление. Имя объекта в подтверждении обрезается визуально после двух строк с доступностью полного названия для screen reader; текст документа целиком не копируется в диалог.

## 6. Приватность: точность формулировок

Строку `localOnly` из текущего `KashaCopy.kt` нельзя безусловно показывать после подключения внешнего AI. Для фактически локального исполнения: «Обработка выполняется на этом устройстве». Для смешанного режима: «Часть обработки выполняется во внешнем сервисе» с перечнем ролей и провайдеров. «Ваши записи хранятся на устройстве» описывает storage и не скрывает возможную передачу копии внешнему сервису.

На экране согласия заголовки короткие: «Кому передаём», «Что передаём», «Для чего». Содержимое строится по выбранной роли и реальному запросу. Для подбора проекта раскрываются также описания и служебные идентификаторы проектов, если адаптер отправляет их. Объём не расширяется общей фразой «и другие данные».

Для демонстрационного режима формулировки зависят от двух независимых признаков — настоящий ли звук и настоящее ли распознавание. Текущая строка «Запись аудио настоящая» не подходит iOS-заглушке. Допустимые варианты: «Демонстрация интерфейса. Аудио и текст — примеры» либо «Текст — пример. Запись аудио настоящая» при подтверждённом реальном recorder.

## 7. Даты, время, числа

- Таймер записи использует табличные цифры: `00:24`, после часа — `1:00:24`. Ноль не заменяется декоративным прочерком. На паузе elapsed не растёт.
- Screen reader озвучивает «24 секунды», а не «ноль ноль двоеточие двадцать четыре». Обновление не прерывает чтение каждую секунду; текущее время доступно по фокусу, объявления задаются в доступности.
- Metadata заметки: «Сегодня, 13:24», «Вчера, 18:45» или локализованная дата; для другого года добавляется год. В одном списке одинаковый формат.
- В редакторе срока показываются полные дата и время, чтобы «завтра» не было единственным подтверждением. Данные хранятся и форматируются по существующему календарному контракту.
- При автоматическом переносе срока используется фактическое новое время из Core; UI не пересчитывает его независимо. Не заявлять точность DST, пока соответствующий адаптер не проверен.
- Скорость: `1,5×` в русском UI; значение модели остаётся числом `1.5`. Качество — понятная подпись уровня, при необходимости `32/48/64/96 кбит/с` как дополнительная строка.
- Длительность источника относится к реально воспроизводимому файлу. Исходное время записи и время оптимизированного аудио не смешиваются без подписи.
- Не выводить модельный relevance `0…4` как «вероятность 80%». Текстовая метка «Подходит по содержанию» допустима, если рейтинг действительно получен; при ошибке её нет.

## 8. Поля и длинный текст

Label располагается снаружи поля. Placeholder — пример формата или ожидаемого содержания, а не единственная подпись. Необязательность поясняется текстом «(необязательно)» там, где действительно можно оставить пусто; редкие обязательные поля не обозначаются только цветной звёздочкой.

Пример инструкции проекта: «Рабочие встречи, решения по интерфейсу и задачи команды». Пример не записывается в данные. Для результата записи длинный рекламный placeholder не нужен: пустой документ получает короткое «Текст записи».

Пользовательский текст не очищается от emoji и символов, даже если emoji запрещены как украшение интерфейса. Переносы, отрицания, числа и смешанные языки сохраняются. Непрерывная длинная строка визуально переносится, не растягивая экран. Кнопки не сокращаются до неясных «Сохр.» и «Откл.».

## 9. Восемь языков

Поддерживаются локали `ru`, `en`, `es`, `fr`, `de`, `uk`, `be`, `kk`. Выбор по умолчанию — системный язык; для неподдерживаемой локали применяется существующий fallback `en`. Язык интерфейса и фактическая доступность распознавания речи не считаются одним и тем же capability.

Новые строки добавляются сразу во все восемь колонок общего каталога. Склеивание предложений из фрагментов и ручное добавление окончания к числу запрещены. Для количеств и времени применяется единый механизм локализованных форм; если он ещё отсутствует, это отдельная задача shared UI, а не восемь разрозненных экранных условий.

Проверка локализации включает украинские, белорусские и казахские буквы, диакритику западноевропейских языков, знаки валют, длинные имена проектов и комбинируемые символы. Для pseudo-localization увеличивать строки на 40%, не менять данные пользователя. Ни одна локаль не уменьшает шрифт ниже 11sp ради вписывания.

## 10. Критерии

1. Каждый видимый ключ разрешается в строку; нет `null`, имени enum, сырого exception или английского fallback внутри выбранной поддерживаемой локали.
2. Одинаковое действие имеет одинаковую подпись на Главной, в плеере и screen reader.
3. Сообщение об успехе не появляется до подтверждения сохранения.
4. Нет противоречия между локальной/внешней обработкой и видимой privacy-строкой.
5. Нет процентов обработки без фактического progress и процентов релевантности из ранга `0…4`.
6. У каждого отказа есть понятный безопасный выход; текст пользователя остаётся доступен.
