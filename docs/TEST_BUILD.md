# Kasha Test 1.2.0 — версия без нейросетей

Отдельная облегчённая сборка актуальной Kasha для проверки на Mac с Apple Silicon (процессоры серии M). Требуется macOS 13.3 или новее.

В установщике нет моделей Whisper/Qwen и нет движков Whisper/llama.cpp. При запуске модели не скачиваются. Java и автономный аудиодвижок FFmpeg уже внутри; Homebrew, Xcode и отдельная Java не нужны.

## Что можно проверить

Интерфейс, светлую и тёмную темы, запись микрофона, осциллограмму, паузу и продолжение записи, прослушивание, проекты, заметки, ручное редактирование текста, задачи и настройки. Сохранение данных настоящее.

## Что заменено тестовыми примерами

Распознавания речи в этой сборке нет. После записи показывается подготовленный текст, не расшифровка ваших слов. Обработка текста и подбор проекта работают по простым тестовым правилам, без нейросетей. Интерфейс отмечает тестовый режим. Текст можно заменить своим вручную.

Для проверки без микрофона используйте «Попробовать без микрофона». Это тестовый звуковой сигнал и подготовленный текст.

## Запуск

1. Откройте DMG.
2. Перетащите «Kasha Test» в «Программы».
3. Запустите «Kasha Test» из «Программ» и разрешите микрофон при необходимости.

Подпись ad-hoc, без Developer ID и нотариального заверения Apple. При блокировке неизвестного разработчика подтвердите открытие только этого приложения в системных настройках конфиденциальности и безопасности. Не отключайте защиту macOS целиком.

## Данные

Тестовая версия использует отдельное хранилище: ~/Library/Application Support/Kasha Test. Данные основной Kasha не изменяются. Если раньше уже устанавливалась Kasha Test, её тестовые данные сохранятся.

В отчёте сборки отдельно указано: физический микрофон на вашем устройстве не проверен автоматическими тестами.
