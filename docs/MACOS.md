# Установка Kasha для macOS

Обновлено: 14 сентября 2026. Общий статус Desktop: [DESKTOP.md](DESKTOP.md).

Текущий маршрут сборки рассчитан на **Apple Silicon и macOS 13.3 или новее**. Для Intel этот пакет не предназначен.

## Пакет

Используйте DMG из успешного запуска workflow **«Автономный установщик macOS»** (`.github/workflows/macos.yml`). Имя содержит фактическую версию: `Kasha-<версия>-macOS-arm64.dmg`. У GitHub Actions артефактов ограниченный срок хранения; наличие старого успешного запуска не гарантирует доступность его файла.

Эта инструкция не объявляет выпуск последнего коммита. Размер, SHA-256 и результат проверки берутся из `SHA256SUMS.txt` и `BUILD-REPORT.json` того же запуска, что и DMG. Данные прежней версии 1.0.0 к новой сборке не применяются.

## Установка

1. Откройте DMG и перетащите Kasha в Applications («Программы»).
2. Запустите Kasha из «Программ».
3. Разрешите использование микрофона, когда приложение запросит доступ.

В пакет включаются Java, аудиодвижки, Whisper Small и Qwen3-4B Q4_K_M. Установленному приложению не нужны Homebrew, Xcode, JDK, CMake или отдельная загрузка базовых моделей. Основной локальный сценарий не требует аккаунта и внешнего сервера.

## Безопасность и микрофон

Текущий скрипт применяет локальную ad-hoc подпись. Сертификат Developer ID и нотариальное заверение Apple этим скриптом не предоставляются. Это не равно подписанному публичному релизу.

Если macOS блокирует доверенную вами сборку, используйте разрешение для конкретного приложения в «Системные настройки → Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком.

При недоступном микрофоне проверьте разрешение Kasha и устройство ввода в настройках звука. В app включаются `NSMicrophoneUsageDescription` и entitlement `com.apple.security.device.audio-input`. Наличие этих параметров не заменяет проверку физического микрофона.

## Данные и завершение работы

Данные находятся отдельно от app: `~/Library/Application Support/Kasha`. Замена приложения не должна удалять этот каталог. Для резервной копии закройте Kasha и скопируйте его целиком. Старое веб-хранилище `~/.kasha` автоматически не переносится.

Закрытие окна и поддерживаемая системная команда «Завершить» используют один путь: сохранение общего состояния, закрытие аудио и desktop services. Незавершённое аудио остаётся в локальном WAV-журнале и восстанавливается при следующем запуске. При ошибке сохранения окно не закрывается принудительно.

Напоминания работают, пока Kasha запущена, и зависят от разрешений уведомлений macOS. После полного выхода фонового агента нет.

## Сборка и проверка

Workflow собирает автономный app, проверяет локальную обработку без сети, открывает окно приложения и создаёт DMG. Реальные микрофон, аудиовыход и все системные сценарии требуют отдельной приёмки на Mac. Результат конкретной сборки находится в её отчёте; старые verification-документы не подтверждают автоматически новые изменения.
