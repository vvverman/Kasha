В main `composeApp/build.gradle.kts` использует `tasks.withType<KotlinCompilationTask<*>>().configureEach { dependsOn(generateKashaIcons) }`, включая Android compile task. Поэтому исправление зависимости генератора из PAR-09 уже существует в базе и сохраняется. В отставшей desktop-ветке оно не должно потеряться. Перенос генерации из исходного каталога и чистая воспроизводимая сборка — отдельная незакрытая часть этапа 2.
