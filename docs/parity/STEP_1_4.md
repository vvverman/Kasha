# Шаг 1.4 — запуск, восстановление и транспорт в Core

Статус этого commit: код внесён целиком, локальная JVM-компиляция и тесты пройдены; новая матрица CI должна проверяться по этому commit. Физическая приёмка и весь этап 1/5 не закрыты.

## Объём

Существующий `brain.application.KashaApplication` теперь координирует запуск, автозапись, восстановление, таймер, запись/плеер, перемотку и периодическое чтение данных. Общий UI читает `StateFlow` и передаёт команды, сохраняя навигацию и оформление. Составное сохранение текста задачи перед выполнением тоже принадлежит Core. Существующие `BrainData`, `StudioRepository`, `RecorderSessionGateway`, `PlaybackSessionGateway` и `CaptureRecoveryCoordinator` переиспользованы.

В подтверждении удаления сохраняются тип и ID объекта; смена состояния не превращает отмену записи в удаление результата/задачи. Подготовка отмены ставит ожидаемую запись на паузу; системное закрытие диалога не возобновляет микрофон. Финализация после отмены команды только перечитывает факты в ограниченном finalizer, не повторяет обработку/удаление. Новый старт сначала перечитывает данные.

Восстановление готового файла не запрещено из-за работающего плеера и не останавливает его. Ошибки напоминаний не открывают глобальное окно; используются существующие тексты в контексте задач. Новые разделы, настройки, провайдеры, схемы хранения и платформенные экраны не добавлены.

Применены serialization и Compose compiler plugins 2.4.20, библиотеки coroutines/core/test 1.11.0 и datetime 0.7.1 из CI проекта. JUnit 4 и `runTest` использованы без замены тестовых тел.

В текущем commit workflow возвращён к исходному содержимому. Дополнительная инфраструктура для приложения не остаётся.

## Следующая проверка и открытые границы

Проверить штатные KMP/browser, Android, iOS Shared и SideStore CI именно опубликованного кода. Старые зелёные результаты до переноса к нему не относятся. Проверки JVM с тестовыми адаптерами не заменяют микрофон, AI, уведомления и recovery на устройствах.

Legacy-адаптеры ещё существуют: отсутствие identity-aware отмены не исправляется переносом её команды в Core. Реальные Android AI-роли, iOS locale/AI alignment, Web reminders, Desktop-интеграция и полная доводка общего UI остаются в утверждённом плане. Не расширять приложение ради этих задач.
