# Desktop — перенос существующих системных частей в общую базу

Источник: `architecture/six-shells`, commit `e1053103c6c8e93b8f81f3fa7caf5ba97750dbdb`.
База переноса: `6a90bfc1e570ae1fed9ac20db53868fd2654d833`.

Перенесены системные пути macOS/Windows/Linux, поиск `.exe`, instance lock, обработка системного Quit, адаптер уведомлений и форматы пакетов Dmg/Msi/Exe/Deb/Rpm. Путь desktop-модуля остаётся `desktopApp`; старые Core/UI/Android деревья источника не переносятся. Новый RecorderSessionGateway и актуальный DesktopAudio сохраняются.

Не создаётся второй набор Mac/Linux secret store в Desktop. Используется существующий общий runtime `JvmCloudAiGateway` и его factory. Windows secure storage этого runtime всё ещё требует отдельного подключения; эта граница не считается закрытой лишь из-за переноса упаковки.

В notifier исправлен прежний молчаливый успех при ненулевом exit code; недоступный adapter не выдаёт успешную доставку. Заголовок системного уведомления — имя Kasha, тело — исходный текст задачи. Календарные расчёты не переносятся в ОС.

Добавлена матрица общих Core/desktop-тестов на трёх ОС, адаптированная из существующей `desktop-adapters.yml` к актуальным путям. Исходные проверки не отключаются. Новые проверки покрывают пути, обнаружение ОС, exe, блокировку экземпляра и передачу ошибок notifier.

Это интеграция исходников, не утверждение о готовности всех установщиков и не проверка настоящего микрофона или системной доставки. Матрица текущего commit должна быть прочитана после её завершения. Полная PAR-01/приёмка остаётся открытой; Web-пакет ранее не опубликован из-за явной блокировки инструмента.
